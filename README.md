Game Created Using Ursina Game Engine and Python 3.14.6.
This Game Uses 1 Player Ship and Multiple Asteroids and Enemy Ships.
The Number of Asteroids and Enemy Ships are Selectable (Max = 30 each).
Also, The Number of Guns for All Ships are Selectable up to 3 Guns Each.
All Ships Change Texture Depending on The Number of Guns Selected.
The Enemy Ships Target the Player Ship When Aligned and in Range.
The Alignment is Approximately 3 degrees, and the Range is
0.5 * X and 0.5 * Y From Center Screen.
The Enemy Ships are Deadly if Aligned and in Range Unless you Move Quick.
The Score is Determined by Hits vs Misses. Each Miss = -0.5 points.
If You Create an Executable Using Pyinstaller, Read the Ursina_fix.rft.
